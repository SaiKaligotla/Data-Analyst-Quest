How to play. Levels unlock in order. Each one teaches a concept, then makes you answer — by writing code, picking an option, or working out a number.
  • Try before hinting. Three hints per level, each one more explicit. Fewer hints, more XP.
  • Target output shows the real answer your code should produce — computed from actual data, not invented.
  • Yellow callouts in lessons flag the things interviewers actually ask.
  • Day 7: replay the boss levels in every game. If any feel shaky, that is your revision list.
One honest limitation. There is no database or Python runtime in your browser, so code answers are checked structurally — the game verifies your answer contains the right clauses and functions. It will catch a missing GROUP BY or the wrong join type, but not a typo in a column name. Always compare your result against the target output shown.
